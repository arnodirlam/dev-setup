# Elixir updates

- Apply the available `elixir-development` skill when changing Elixir code.
- Inspect `mix.exs`, `mix.lock`, Elixir/Erlang pins, and CI configuration. In umbrellas, include child manifests and shared dependency resolution.
- Use `mix hex.outdated` when an overview is needed; add `--all` for transitive dependencies or a package name to inspect constraints. Exit code 1 can mean outdated dependencies were found.
- Make required Elixir/OTP upgrades explicit prerequisites or part of the coupled migration. Check adapter and transitive constraints; ecosystem membership alone does not require a shared batch.
- Check application configuration, compile-time behavior, database interactions, and generated frontend assets where release notes indicate impact.
- Compilation warnings are displayed by default: [`mix compile`](https://mix.hexdocs.pm/Mix.Tasks.Compile.html) defaults to `--all-warnings` (except on errors), including warnings from previous application compilations. `--warnings-as-errors` changes failure behavior, not warning visibility. Preserve project check flags; verify installed-version behavior with `mix help compile`. Cached dependency builds may not replay their warnings: use comparable dependency compilation coverage before and after, rebuilding relevant dependencies when needed, or record that coverage gap.
- [Hex 2.5+](https://hex.pm/blog/hex-v25-released) prints security advisory warnings during `mix deps.get` and `mix deps.update` without extra flags/configuration; those warnings do not fail the command by default. Run [`mix hex.audit`](https://hex.hexdocs.pm/Mix.Tasks.Hex.Audit.html) as a separate invocation before and after each batch to check the lockfile for advisories and retired packages; findings cause a non-zero exit status. Track ignored findings separately where reported. Older Hex versions only audit retirements: use an existing project security audit if available, otherwise report the security coverage gap rather than treating retirement-only output as a clean security audit.
